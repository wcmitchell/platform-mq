# Deprecated Deploy Templates

These OpenShift/Strimzi resource templates are no longer actively deployed via app-interface. They are retained as historical reference for understanding prior configurations (e.g., pre-MSK Kafka clusters, Debezium connectors, MirrorMaker2 variants).

For current deployment configurations, see the files in `deploys/openshift/` and the corresponding saas files in app-interface (`data/services/insights/strimzi/`).
